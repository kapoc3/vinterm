**VinTerm** es un cliente SSH y emulador de terminal moderno, altamente seguro y elegante, diseñado para optimizar la gestión de servidores con SFTP integrado, telemetría en tiempo real y seguridad de grado empresarial.

*Este proyecto está nombrado con orgullo en honor a mi hijo, Vicente.*

## 🌟 Características

*Conoce todas las características en detalle en nuestro sitio web: [https://kapoc3.github.io/vinterm/#features](https://kapoc3.github.io/vinterm/#features)*

- **🤖 Asistente IA Vincent:** La única consola que te permite asociar tus modelos de IA favoritos.
- **🧠 Agentes de IA Personalizados y Aislamiento:** Genera agentes usando lenguaje natural. Aislamos la seguridad del contexto de IA.
- **🔒 Bóveda de Seguridad:** Tus contraseñas y llaves privadas nunca se guardan en texto plano. Cifrado AES-256-GCM de grado militar.
- **📊 Telemetría de Servidores:** Monitoreo de CPU, Memoria y Disco en tiempo real integrado en la barra de estado.
- **📂 SFTP Integrado:** Gestiona archivos sin problemas junto a tus sesiones de terminal.
- **🎨 Temas Premium:** Hermosa interfaz construida con variables CSS. Cambia entre el elegante Modo Claro y Oscuro.
- **☁️ Google Cloud Platform:** Integración nativa con Google Cloud para tus instancias de Compute Engine.
- **🛡️ Arquitectura Zero Trust:** Construida desde cero para máxima seguridad con estrictas políticas CSP.
- **💛 Impulsada por la Comunidad:** Completamente de código abierto y financiado por la comunidad.

## 🤝 Comunidad y Contribuciones

VinTerm es un proyecto de **código abierto** construido para y por la comunidad. Creemos en el conocimiento abierto, la mejora compartida y la seguridad transparente.

### Cómo Contribuir
1. **Haz un Fork** del repositorio.
2. Crea una nueva rama: `git checkout -b feature/CaracteristicaIncreible`
3. Haz commit de tus cambios: `git commit -m 'Añadir CaracteristicaIncreible'`
4. Haz push a la rama: `git push origin feature/CaracteristicaIncreible`
5. Abre un **Pull Request**.

¡Revisa nuestro [Resumen de Arquitectura](docs/ARCHITECTURE.es.md) si deseas comprender cómo está construida la aplicación antes de contribuir!
